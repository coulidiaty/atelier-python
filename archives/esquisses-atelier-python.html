Atelier Python esquisse

Même leçon, trois styles. Change de style en haut quand tu veux : ta progression est gardée. Le code Python s'exécute vraiment dans la page.

Comment cette leçon aide à apprendre
  • Tu codes dès la première minute, pas de gros pavé à lire.
  • Tu devines avant d'exécuter : ça oblige à réfléchir au lieu de lire.
  • Tu tapes toi-même : le copier-coller est désactivé dans les exercices.
  • Des indices progressifs, jamais la solution d'un coup.
  • Les erreurs sont expliquées en français, avec la ligne en cause.
  • La mémoire de Python est visible : chaque variable apparaît comme une boîte.
  • Chaque leçon finit par un récap court et le passage à VS Code.
