# Vision : du cours Python au « Duolingo du code »

## Aujourd'hui
L'Atelier Python est un cours pour la classe CS28 : les bases de Python (7 chapitres, 44 leçons), puis la POO en Python et en Java (10 chapitres, 51 leçons). Chaque leçon est courte, on code dans la page, et le jeu (XP, série, badges, classement de la classe) donne envie de revenir chaque jour.

## Le cap à long terme
Faire de l'Atelier un **Duolingo du code** : apprendre à programmer quelques minutes par jour, sur son téléphone, dans plusieurs langages, avec une progression guidée et un jeu qui motive.

Ce qui fait déjà la base de cette idée :
- des leçons de 8 à 15 minutes, découpées en petites étapes ;
- de la pratique tout de suite, corrigée automatiquement, avec des erreurs expliquées en français ;
- une série de jours, un objectif quotidien, de l'XP et des badges ;
- une classe et un classement qui repart à zéro chaque semaine.

## Étapes possibles (dans l'ordre, sans date)

1. **Stabiliser avec la classe CS28.** Écouter les retours, corriger, mesurer ce qui marche (leçons abandonnées, exercices trop durs).
2. **Outils pour le responsable de classe.** Une page avec les inscrits, leur progression, et la modération des pseudos.
3. **Révisions espacées.** Faire revenir les notions oubliées au bon moment, comme les cartes de Duolingo.
4. **Plusieurs cours.** Découper le moteur (voir la cible dans [ARCHITECTURE.md](ARCHITECTURE.md)), puis ajouter un deuxième cours : Java exécuté pour de vrai, JavaScript ou SQL.
5. **Plusieurs classes.** Chaque prof ou délégué crée sa classe avec un code ; un tableau de bord par classe.
6. **Appli mobile soignée.** L'appli installable existe déjà (PWA). Ajouter les notifications de rappel (« ta série t'attend »), puis éventuellement publier dans les magasins d'applications.

## Ce qu'on garde quoi qu'il arrive
- Gratuit et sans publicité pour les élèves.
- Le site marche sans compte ; le compte et la classe restent un choix.
- Des explications courtes, en français, avec Pyo.
- Le moins de données personnelles possible.
